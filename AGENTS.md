# AI contribution entrypoint

Before changing this repository, read:

1. `docs/对接开发指南.md` (Chinese integration guide)
2. `docs/integration-development-guide.md` (English integration guide)
3. `docs/项目约束.md`
4. `docs/阶段开发计划.md`

Use the Resource Contract for ordinary resources, keep PostgreSQL/Redis as the runtime services, keep module translations in JSON, write tests before production changes, and report reproducible verification commands.
