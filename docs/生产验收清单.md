# 生产验收清单

这份清单用于目标环境发布前的人工签字和证据归档。它不是本地健康页面的替代品，也不会自动修改 Laragon 管理的 PostgreSQL、Redis 或进程。

## 配置与安全

- [ ] `ENVIRONMENT=production`，数据库为 PostgreSQL，Redis 已配置。
- [ ] JWT Secret 为随机值且至少 32 字符；Trusted Hosts 已启用。
- [ ] `API_DOCS_ENABLED=false`、`VITE_DEMO_LOGIN_ENABLED=false`。
- [ ] 登录、Refresh、Revoke 在 Redis 故障时 fail-closed。
- [ ] HTTPS 入口返回 CSP；HTTPS 请求返回 HSTS。

## 数据与恢复

- [ ] 在隔离 PostgreSQL 上执行 `alembic upgrade head`。
- [ ] 通过 `pg_dump`/`pg_restore` 完成恢复演练，并核对 Alembic 版本、Users、Roles、Permissions、Audit Logs、Tasks。
- [ ] 已记录备份文件校验值、保留周期、恢复负责人和回滚决策人。

## 运行时故障

- [ ] Redis 停止时 `/api/v1/health/ready` 为 `degraded`，写操作和认证安全状态拒绝继续。
- [ ] Worker 停止后，lease 超时任务可重新排队或进入 dead 状态。
- [ ] Scheduler 停止后不会伪造任务成功；恢复后可重新发布 pending 任务。
- [ ] 使用 PID/服务编排停止本项目进程，不按进程名杀进程。

## 验证命令

```powershell
.venv\Scripts\python.exe -m pytest -p no:cacheprovider server/tests -q
cd admin; pnpm typecheck; pnpm test -- --run; pnpm build
scripts\production-acceptance.ps1 -SkipDatabase
```

提供隔离验收库后，再设置 `TEST_DATABASE_URL` 运行 PostgreSQL 演练测试。外部 Telemetry 本阶段不在范围内。
