# P3.6 Telemetry 与 HTTP Client 设计

**状态：** 基础实现已完成，待接入外部导出器

## Telemetry

- `RequestContext` 自动生成或透传 `X-Trace-ID`，响应回写同一 Trace ID。
- Access Log 同时记录 Request ID 和 Trace ID。
- `MetricsRegistry` 提供进程内 Counter/Histogram，当前记录 HTTP 请求次数和耗时。
- `python -m server.app telemetry` 输出当前进程 Metrics 快照。
- 当前不绑定 OpenTelemetry SDK、Prometheus Exporter 或外部监控服务；后续可在 Registry 边界增加 Exporter。

## HTTP Client

- `server/app/core/http_client.py` 统一封装 `httpx.AsyncClient`。
- 支持超时、请求头、Request ID 和 Trace ID 传播。
- 支持 async context manager，调用方必须关闭 Client，避免连接泄漏。
- Mail、File Storage、AI SDK、gRPC 等适配器只在出现真实业务需求后建立，不提前进入 Core。
