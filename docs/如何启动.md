# 本地启动与数据库切换

> 这是启动约定；架构约束见 `docs/项目约束.md`，阶段门禁见 `docs/阶段开发计划.md`。当前已具备 FastAPI、SQLAlchemy ORM、Alembic、Vue 和 Redis 开发基线。

## 1. 必备环境

- Python 3.13+
- Node.js 18+、pnpm
- PostgreSQL 或 MySQL（二选一即可启动；双库验收时都要执行）
- 开发默认启用 Redis；Redis 缺失时基础后台仍应启动，并将 Cache 降级为 Memory、任务队列置为 deferred/pending

## 2. 环境变量

```env
# PostgreSQL
DATABASE_URL=postgresql+asyncpg://app:secret@127.0.0.1:5432/fastapi_admin_dev

# 或 MySQL
# DATABASE_URL=mysql+aiomysql://app:secret@127.0.0.1:3306/fastapi_admin_dev?charset=utf8mb4

JWT_SECRET=change-me
REDIS_URL=redis://127.0.0.1:6379/0

# API 文档（开发环境）
API_DOCS_ENABLED=true
SCALAR_TELEMETRY=false
SCALAR_AGENT_ENABLED=false
SCALAR_THEME=KEPLER
# 本地登录页显示演示账号；生产环境必须设为 false
DEMO_LOGIN_ENABLED=true
# VITE_DEMO_LOGIN_ENABLED=false
# SCALAR_JS_URL=
# SCALAR_PROXY_URL=
```

只修改 `DATABASE_URL` 即可切换数据库；不要为了切换数据库修改 Model、Repository、Service 或 Router。开发环境默认同时启用 Redis。

## 3. 安装与迁移

后端依赖必须包含 `sqlalchemy`、`alembic`、`asyncpg`、`aiomysql`、`scalar-fastapi`；前端使用 pnpm。依赖安装前按仓库网络规则执行 `wslnet ctx`。

```bash
alembic upgrade head
uvicorn server.app.main:app --reload
pnpm install
pnpm dev
```

本地实时预览默认使用 `http://127.0.0.1:4181/`，本项目后端开发 API 使用 `http://127.0.0.1:8012/`；如果端口被占用，修改 `admin/vite.config.ts` 和启动参数后保持前端代理一致。`8011` 由其他本地服务占用，不属于本项目。

不要手工执行 `CREATE TABLE`、`ALTER TABLE` 或 SQL 文件；数据库结构只通过 Alembic。

## 4. 最小检查

```bash
curl http://127.0.0.1:8012/api/v1/health
curl http://127.0.0.1:8012/openapi.json
# 浏览器打开：
# http://127.0.0.1:8012/docs/scalar
\.venv\Scripts\python.exe -m pytest server/tests -q
pnpm build
```

## 4.1 本地演示账号

迁移完成后，使用 ORM 种子脚本创建登录页演示账号；脚本不会在应用启动时自动执行：

```powershell
\.venv\Scripts\python.exe -m server.scripts.seed_demo_admin
```

登录页会显示 `integration-admin / integration-password`，支持分别复制或一键填充并登录。该账号和密码仅用于本地开发，生产环境必须关闭 `DEMO_LOGIN_ENABLED` 和 `VITE_DEMO_LOGIN_ENABLED`，并使用正式的用户初始化流程。

## 5. Scalar API 文档

开发环境访问 `http://127.0.0.1:8012/docs/scalar`。页面直接读取 FastAPI 的 `/openapi.json`，不维护第二份接口定义；接口变更后先检查 JSON，再检查 Scalar 页面和 SDK 生成。

Scalar 集成由 `scalar-fastapi` 提供，生产环境将 `API_DOCS_ENABLED=false`，如确需开放文档，必须增加内网/allowlist/管理员鉴权。开发默认关闭遥测和 Scalar Agent；Bearer Token 通过登录接口获得后，只能调用当前用户有权限的接口。

## 6. 双数据库门禁

分别设置两套 `DATABASE_URL` 并执行：

```bash
alembic upgrade head
alembic downgrade base
alembic upgrade head
\.venv\Scripts\python.exe -m pytest server/tests/integration -m integration -q
```

当前集成测试通过 `TEST_DATABASE_URL` 或 `DATABASE_URL` 读取目标库，并覆盖 Users/Roles ORM CRUD 和关联关系。两种数据库都通过后，才能声明“可切换”；只在 PostgreSQL 通过不能视为完成。

## 7. AI Elements Vue

在前端 P1/shadcn-vue 基线完成后按需安装：

```bash
npx ai-elements-vue@latest add conversation message prompt-input
```

组件源码进入 `admin/src/components/ai-elements/`。真实 AI Provider 在 P6 才接入；没有 AI 配置时，Admin Shell、登录、标准 CRUD 和 OpenAPI 仍必须可用。

## 8. Windows/Laragon Redis

`D:\laragon\usr\packages.conf` 已加入 Redis Windows x64 带 Service 的下载项。安装后默认监听 `127.0.0.1:6379`，使用以下命令验证：

```powershell
redis-cli.exe ping
# 期望：PONG
```

如果使用带 Service 的压缩包，优先通过 Windows 服务启动；不要在项目代码里启动或停止 Redis 进程。项目只负责连接、健康检查和降级。
