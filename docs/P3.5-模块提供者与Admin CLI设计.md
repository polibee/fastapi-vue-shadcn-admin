# P3.5 Module Provider 与 `admin` CLI 设计

**状态：** 基础骨架已实现

## Module Provider

- `server/app/core/modules/__init__.py` 提供 `ModuleSpec` 和 `ModuleRegistry`。
- Module 通过 `register()` 注册扩展，应用启动时执行 `boot()`。
- Registry 只负责生命周期，不承载认证、权限或业务数据访问。
- 现有业务 Router 继续由 FastAPI 统一挂载，后续模块可逐步迁移为 Provider 注册。

## `admin` CLI

当前支持：

- `python -m server.app modules`：列出内置模块。
- `python -m server.app health`：检查数据库和 Redis。
- `python -m server.app generate <resource>`：转发到 CRUD Generator。
- `python -m server.app sdk`：输出 TypeScript SDK 生成命令。
- `python -m server.app migrate [revision]`：调用 Alembic 执行迁移，支持 `--dry-run`。
- `python -m server.app seed`：执行开发管理员种子，支持 `--dry-run`。
- `python -m server.app worker`：启动 ARQ Worker，支持 `--dry-run`。
- `python -m server.app scheduler`：以调度模式启动任务恢复 Worker，支持 `--dry-run`。
- `python -m server.app doctor`：只读检查数据库、Redis、模块、Telemetry 和安全配置。

安装项目包后可使用 `admin` 命令；CLI 不复制 Alembic、Uvicorn、pnpm 的能力，而是作为统一开发入口进行编排。
